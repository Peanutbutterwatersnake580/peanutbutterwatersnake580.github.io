🛠️ Three Powerful Ways to Change Your IP

🌐 1. Proxy Engine (Change Public IP)

This feature rotates your public IP address through a list of proxy servers. When you browse the internet, websites will see the proxy's location instead of your own. This is perfect for:

  • Accessing content restricted in your region
  • Anonymizing your browsing activity
  • Avoiding tracking by websites

🏠 2. LAN IP Switcher (Local Network)

This tool changes your computer's IP address on your local network (the network in your home or office). Useful for:

  • Fixing network conflicts
  • Connecting to specific devices or printers
  • Setting up a simple home or work network

🌍 3. Cloudflare WARP over WireGuard (With Country Selection)

This connects you to Cloudflare's secure WARP network using WireGuard technology. You can choose which country you appear to be in. Great for:

  • Adding a layer of encryption to your internet connection
  • Selecting a specific country for streaming or gaming
  • Getting a more stable and faster connection

📖 Frequently Asked Questions (FAQ)

Is KitoIP safe to use?

Yes. KitoIP is an open-source project, meaning its code is publicly viewable. It does not collect any personal data, does not contain ads, and has no hidden functions. It only does what this page tells you: changes your IP in one of three ways.

Do I need to install anything else?

No. KitoIP is pure PowerShell. If you use Windows 10 or Windows 11, you already have everything needed. There are zero extra downloads, no Java, no .NET framework to install separately, no drivers.

Will this slow down my computer?

No. KitoIP only runs when you open it. It doesn't start automatically with Windows and doesn't run in the background. When you're done using it, close the terminal window and it's completely gone.

What if I mess something up?

Don't worry! The LAN IP switcher has an option to automatically set everything back to automatic (DHCP). And you can always restart your computer to restore your network settings if needed. For the proxy and WARP options, closing the tool automatically stops the proxy or VPN connection.
